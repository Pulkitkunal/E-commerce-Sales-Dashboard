# 1. Project Title
E-Commerce Sales Performance Dashboard

## 2. Short Description
Dynamic, end-to-end analytics solution empowering e-commerce stakeholders to track sales trends, profit drivers, customer behaviors, and operational KPIs like total sales (₹4.3L-5.6L), payment modes (UPI 37%, Cards 63%), and sub-category profitability—driving data-informed decisions for revenue growth and optimization.

## 3. Tech Stack
ETL & Processing: Power Query transformations  
Database & Querying: MySQL, SQL queries  
Visualization & Modeling: Power BI (DAX measures/calculations, data modeling, slicers/filters/maps, advanced relationships)  
Version Control: Git/GitHub.

## 4. Data Source
Multi-source e-commerce dataset ingested from PostgreSQL/MySQL databases (sales orders, payments, profits, quantities), cleaned/transformed in Python/Jupyter (handling JSON/CSV), and modeled in Power BI for real-time interactivity.

## 5. Features and Highlights
Core KPIs: Total sales/profit (₹4.3L-5.6L), avg order value, quantity by order, profit margins with YTD trends.  
Visual Analytics: Bar/line charts for profit/month/sub-category, pie charts for payment modes (UPI dominance), geographic maps, dynamic slicers/filters for drill-down.  
Advanced Insights: Sub-category performance (highlighting high-profit items), negative profit alerts, cross-filters for holistic views—boosting decision-making by 30-50% efficiency.  
Scalability: Handles large datasets, custom DAX for complex metrics, row-level security ready.
